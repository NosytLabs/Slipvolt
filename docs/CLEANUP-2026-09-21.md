## Changes in this pass

- **Trustworthy network snapshots:** failed refreshes stay stale during retry backoff; snapshots older than five minutes become unavailable. Cache intervals use a monotonic clock, separate from displayed timestamps. Impossible calendar dates are rejected. Concurrent reads retain coalescing and independent copies.
- **Bounded housekeeping:** security-table cleanup runs at most once per minute per Store instance, deleting at most 1,000 expired rows per table per pass. Rate admission and session expiry still run on every relevant request. Rejected requests can commit housekeeping without being admitted.
- **Transaction recovery:** interrupts roll back open SQLite transactions instead of leaving a shared connection in a transaction. A wallet index avoids scanning all sessions during wallet-wide sign-out.
- **Robust streamed replies:** the browser recognizes LF, CRLF and CR event boundaries even when split across byte chunks. It stops at a complete `[DONE]`, rejects truncated/malformed replies, enforces a cumulative size bound, and cancels/releases the reader. It does not retry paid inference.
- **Less rendering work:** one received stream chunk produces at most one text update even when it contains many events.
- **Request-check cleanup:** editing inputs or changing accounts aborts obsolete preflight requests. Old success styling is cleared immediately; an older request cannot unlock the button while a newer check is pending. Timeouts are bounded and their timers are cleared.
- **Complete preview packaging:** a missing required stylesheet now fails the build before replacing the previous output. README verification commands work with the tracked non-executable shell script (`sh scripts/verify.sh`).

The previously pending credential isolation, no-inference preflight, setup doctor, status page, connection kit and diagnostic report remain included. Help, Privacy and Service Rules are preserved.

## Reproduce

Install the pinned development dependencies and Chromium, then run:

```sh
python -m pip install -r requirements-dev.txt
python -m playwright install chromium
sh scripts/verify.sh
```

`CHROMIUM_PATH` may select an existing Chromium binary. The verifier does not use paid services. The setup doctor is local-only; real upstream inference requires the separate script's explicit paid opt-in and an owner-controlled credential.
