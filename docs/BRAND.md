## Identity

- Warm white `#F5F2E8`, charcoal `#151515`, lime `#C7FF5E`, and violet `#7867FF` for the interface. The illustrated mark uses the closely matched `#C9F564` / `#17211D` palette.
- Use `public/assets/brand-mark.svg` for the mark and `public/favicon.svg` for the browser icon.
- Use `public/assets/holdbyte-hero.webp` for the hero illustration. It has a transparent background, is 1,254 × 1,254 pixels, and is about 95 KB. Declare its dimensions in markup to avoid layout shifts.
- System fonts; no remote font, icon or animation dependency.
- Clear actions: Open workspace, Connect wallet, Send, Start new chat. Avoid invented user counts, unlimited-use claims, price predictions and vague performance claims.

The official token link is derived from the configured mint, and appears only when `TOKEN_LAUNCHED=true`. Verify the listing before enabling it. A holding does not guarantee service capacity. Keep provider, funding and control details accessible from the footer and Help.
