Get your first response

  1. Check the published token mint, holding threshold, and allowance. An unconfigured mint is not a token launch.
  2. Connect Phantom or Solflare and sign the login message. It is not a transaction or token approval.
  3. Select Create API key. Save the full sv_ key when it appears; it is shown once.
  4. Choose a live model and send a prompt. Open Request settings to change the output budget or check the request first.

Use Write, Code, or Understand to fill an editable draft. Follow-up questions include previous messages in this tab, which count toward your allowance. Open the conversation history to review them; Start new chat clears them. Copy or download a completed answer or the retained chat. Ctrl/Cmd + Enter sends the draft.

You do not need a GNK wallet or OpenBroker account. Never enter an obk- key, private key, or seed phrase. Mobile-wallet browser support still needs live testing; WalletConnect is not promised.

Connect an app

Use your deployed Holdbyte origin with /v1. Existing SLIPVOLT_* names remain compatible during the display-brand migration. Keep keys on your server, outside browser bundles and repositories.

export SLIPVOLT_BASE_URL="https://YOUR_DEPLOYED_HOST/v1"
# Set SLIPVOLT_API_KEY privately.
curl "$SLIPVOLT_BASE_URL/models"

Save this request as request.json with a model returned by the live catalog:

{
  "model": "MiniMaxAI/MiniMax-M2.7",
  "messages": [{"role": "user", "content": "Explain an API in one sentence."}],
  "max_tokens": 1024,
  "stream": false
}
curl --fail-with-body -sS "$SLIPVOLT_BASE_URL/chat/completions" \
  -H "Authorization: Bearer $SLIPVOLT_API_KEY" \
  -H "Content-Type: application/json" \
  --data-binary @request.json

Request schema · Live catalog · Source-labelled model policy

The API implements Text-only Chat Completions, SSE streaming, function definitions, and returned tool calls. Holdbyte never executes tools. It does not implement Responses, Assistants, embeddings, images, audio, vision, files, or fine-tuning.

Understand the allowance

AI tokens are text units, not the coins in your wallet. Input and output both count. Every key for one wallet shares the same quota. The daily window resets at 00:00 UTC with no rollover; unresolved reservations remain held for review.

Requests must fit the model context, remaining wallet allowance, shared pool, GNK funding, and concurrency limits. Prompts are not silently shortened. The default local output cap is 4,096 tokens, with 30 requests per minute and four concurrent requests per wallet. Provider acceptance can be lower; the workspace shows the deployed policy.

No checkout or automatic overage billing is enabled. Rate-card values are operator planning inputs, not a customer price. Provider charges, retries, hosting, and RPC still consume project resources, and a reservation can differ from the final provider charge.

Fix a failed request

ResponseWhat to do
400 / 422Check the schema, model ID, fields, and output cap. Do not repeat an unchanged invalid request.
401 / 403Use a valid customer key, then check finalized holdings and wallet status.
409That Idempotency-Key was already used. Duplicate protection is not a replay of the old response.
413Reduce the body. Payload size and model context are separate limits.
429Read Retry-After. Wait for the stated rate, concurrency, or allowance window.
502 / broken streamThe outcome can be uncertain and a reservation can remain held. Record the request ID and do not retry blindly.
503Check status for maintenance, funding, catalog verification, capacity, or reconciliation.

Record X-Request-Id when present. An SSE error can carry its own request ID. Use a unique Idempotency-Key for each intended operation; changing it to bypass an uncertain result can cause duplicate work.

Manage keys, sessions, and usage

Lost key: create a replacement, update your app, then revoke the old key. Full secrets cannot be retrieved. Leaked key: revoke it immediately or use Revoke all API keys.

Shared device: use Sign out all devices. This ends browser sessions but does not revoke API keys. Disconnecting the wallet extension alone may leave the site session active.

Download recent usage after wallet sign-in. The CSV contains the latest 100 records, not a complete archive. Estimated reservations are not settled cost or a customer bill.

Keep token access and compute funding separate

Holding qualifies a wallet for finite access. It is not staking, an on-chain API key, a treasury share, or a GNK redemption claim. Native GNK funds inference; WGNK on Ethereum and the Solana project token are separate assets.

Buying a market token does not replenish the operator’s OpenBroker account. Do not send SOL or SPL tokens to a Gonka deposit address. Read the funding guide for the asset and custody boundaries.

Ask for help without exposing secrets

For a non-sensitive software bug, use GitHub issues. Include the page, UTC time, HTTP status, model ID, steps to reproduce, and a sanitized request ID.

Never publish API keys, authorization headers, cookies, private RPC URLs, seed phrases, private prompts, or raw usage exports. A private account and security channel has not been published yet, so do not post personal disputes or exploit details in a public issue.
