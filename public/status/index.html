What a green label does not prove

A listed model is not a completed inference test. A configured token mint is not a verified token launch. Available GNK does not reserve capacity for every holder. Your actual request must still pass wallet, shared-pool, rate and funding checks.

There is no fabricated uptime percentage or transaction history here. Missing data stays unavailable; a failed refresh clears old claims.
